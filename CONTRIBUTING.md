# Współtworzenie

Zgłoszenia błędów i propozycje zmian są mile widziane przez GitHub Issues i Pull Requests.

Przed wysłaniem zmiany:

1. Nie dodawaj plików z `export/`, cache Godot, lokalnej konfiguracji Androida ani kluczy podpisu.
2. Zachowaj spójność z opisem w `docs/mapa_projektu.md` i uzupełnij `docs/changelog.md`, gdy zmiana wpływa na działanie projektu.
3. Sprawdź projekt w Godot na platformie, której dotyczy modyfikacja.

Przesyłając wkład, udzielasz prawa do jego użycia na licencji MIT projektu.
